# 官方声明与运行行为的边界：自制完整记录示例

这是证据格式与调研决策示例，不是已经运行过的产品测试。

**目标：** 判断给定文档是否足以承诺某账号可以导出笔记。目标深度 L2，实际只达到 L1。

**来源：** 本目录 source.md 是自制文档，内容为“An account can export notes”。为测试官方声明类记录，将它放在 public-source 类型；不代表存在真实官方产品。

**结论：** 可以确认文档写了导出承诺（c1，statement/PASS）。不能确认具体账号、版本或实际导出路径（c2，runtime/SKIP）。

**可达性与状态：** 未提供运行中的应用，入口、加载、成功、失败及限制均未覆盖。即使文档没有提到限制，也不能推断无限制。

**替代解释：** 该声明可能适用于不同版本或账号条件；当前材料不足以区分。

**建议与下一步：** 如果产品决策依赖“当前账号能导出”，下一步应在用户允许的环境内验证入口和导出结果。仅凭该文档不能决定兼容性承诺。

**停止原因：** 输入只有文档；继续改写同一来源不会增加证据。记录缺口而不补写虚构运行行为。

```sh
python3 scripts/check_report.py examples/research/report.json
```
