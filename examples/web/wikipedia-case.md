# 示例 A/C：Wikipedia 搜索框与建议

2026-10-08，以全新 Chromium 156.0.8078.4 上下文观察 [Wikipedia 首页](https://www.wikipedia.org/)，无登录。以下是本次测量的摘要；竞品截图、脚本与网络日志保留在仓库外。不是对所有版本/地区的保证。

## A：可用于独立重建的局部规格

| 本次条件/元素 | 桌面 1280×800，DPR 1 | 窄视口 390×844，DPR 1 |
|---|---:|---:|
| searchInput 左上角（CSS px） | 414.90625, 469.671875 | 10, 101.59375 |
| 输入框宽×高 | 394.1875 × 44 | 314 × 44 |
| 字号/行高 | 16 / 25.6 px | 16 / 25.6 px |
| padding（上右下左） | 8 / 64 / 8 / 12 px | 8 / 64 / 8 / 12 px |
| border-radius | 2px 0px 0px 2px | 同左 |

数据来自首次加载后的 computed style 和 bounding rect。窄视口不是 Android 真机；两个快照不能拼成一个固定布局。`border` 简写返回空值，未据此断言无边框。颜色、完整断点、焦点无障碍和加载动画未在此摘要中验收。

独立重建建议：保留 44px 输入高度与右侧语言/操作空间，根据容器做弹性宽度。上述坐标只用于核对参考截图，不能硬编码成响应式规则。字体回退、字体加载时刻会影响几何结果；重建后逐视口测量。仅借鉴布局与行为，不复用竞品图标、图片或脚本。

## C：功能与局部实现链路

入口为首页英文搜索框。输入公开查询 solar system 后，桌面和窄视口均出现六条候选，首条为 Solar System；清空后候选隐藏。未点击文章、未登录、未发起数据写入。

本次请求类型是 script，使用 JSONP 参数。实际加载的 `index-a9b103e1fc.js`（SHA-256 `0016dcc0781b778a90624ef1e0eaad9585ffc895f3f80fb88f5e8a0e3ede229c`）包含输入/聚焦监听、防抖参数 100 ms、请求构造、回调到候选链接的渲染。这个数值是静态配置，不是测出的端到端延迟。

目标 L3，实际 L2 + 局部 L3：网络正文因压缩与大小边界记录 unavailable，没有伪装成空体；响应字段到最终 UI 的完整映射未独立捕获。一次成功无法证明缓存、取消、过期请求处理或失败重试。服务端算法、数据库与完整架构未知。

我方方案可以采用输入状态、请求代次与展示结果分离，补齐空结果、错误、键盘选择、晚到响应和重试测试。这是设计建议，不是对参考产品的额外发现。
